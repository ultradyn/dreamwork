## What was actually interesting

**#132's task was not the format, it was the seam — and the seam already
existed.** The brief warned that a per-second clock must not ride the tick's
`innerHTML` re-render. It turned out the page has done exactly the right
thing since `.age[data-mt]`: `setInterval(ages, 1000)` writes `textContent`
into nodes that already exist, and `setContent` re-runs it after every swap.
So #132 is a second data attribute on an existing sweep rather than a
mechanism. The work was in *recognising* that, and then in writing the check
that can tell the two apart — because every format check passes on a page
that re-renders the panel once a second. Only the node-identity check reds on
that, and I confirmed it by injecting exactly that implementation.

**#151 found a bug in #104 by reusing it.** `.dreamin` — the enter-snap class
that makes an arriving element begin at opacity 0 — has never worked for
question cards. `.qa` declares the same three transitions at the same
specificity and *later in the sheet*, so it wins: the card kept a 0.85s
transition and an opacity of 1, animated one frame toward 0, and had the class
removed. Crumbs, which declare no transition of their own, have always been
right. Every arrival in the question list has been a pop-in since #104, under
a matrix row that said "snap, then ease in".

Nobody could have seen it by reading; the component's source is correct and
the override is invisible. It surfaced because mounting the mechanism on a
*second* list made the arrival measurable for the first time — which is the
duplication-as-audit lesson landing again, and this is now its third instance
here. Fixed with `transition:none !important` on the transition alone
(the pose stays overridable), because source order is not a contract.

**Three injections lied to me, and the liar was the reporting path.** The
guard printed its checks at the tail, so a script that threw part way through
printed nothing at all — and "no FAIL lines" is indistinguishable from "no
failures". `not-top` looked like a check that proved nothing; it was a check
that had never been reached. Printing from an exit handler fixed it and caught
a real crash within the hour (a backtick inside a template literal).

**One gate needed a case constructed for it.** #151's new-SHA gate looks
unfalsifiable: delete it and a quiet tick still moves nothing, because
`regroupCards` early-returns for a row that did not move. The gate is only
observable when the rows move for some *other* reason — which is the case it
exists for. So the guard makes them move (it writes an unreadable
questions.md, which puts #136's warning above the panel) and requires them to
arrive with the layout rather than travel to it. That injection now reds
exactly one check.

## Judgement calls, stated because they were mine

- Under a minute renders `00m 12s ago` rather than `12s ago`: two units always,
  so the column never changes width, and seconds-old is exactly when he is
  watching. Past 100 days the day count widens and the second unit does not.
- #141's grey is keyed on `questions_health`, not on the count. An unreadable
  file gives the same zero, and a calm grey "nothing to answer" two lines
  under #136's amber warning would be the page contradicting itself.
- #141 folds the *whole* section, awaiting-fold cards included. That is what
  keeps it a standalone `expand` under the fold-motion contract: nothing that
  moves is left below the toggle. The summary names what is inside, so a
  collapsed panel does not hide the in-flight thing.
- The commits panel went above dreams, below `qHealth`. A fault is one line
  and usually absent; nothing else changed order.
