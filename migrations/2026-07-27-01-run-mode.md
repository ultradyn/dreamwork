# 2026-07-27 — main-dreamer run mode is machine-local

## What changed

The dashboard can set a main-dreamer **run mode** (`lackadaisical` /
`hot` / `assisted`) via a 10-second armed control. The authoritative
value lives in `.dreamwork/run-mode` (one line, closed vocabulary). On a
real change, `POST /run-mode` also appends one `watch-events.log` line so
a tail monitor can wake the loop. Identical final submissions are
idempotent (200, no second event). `hierarchical` is UI-only and disabled
until #264/#288.

This is **operational posture on this host**, not a portable project
preference like `watch-tint`. A committed mode would surprise the next
clone.

## How to apply

Add one line to the **target's** `.gitignore`:

```
.dreamwork/run-mode
```

If the target keeps a frozen capture fixture the way this repo does,
ignore any fixture copy too.

The file itself appears on its own, at the first successful mode change
through a dashboard running this version. Nothing to create, nothing to
backfill. Absent means `lackadaisical`.

Shape: `file-formats.md` (`.dreamwork/run-mode`). Checked by `lint.py`.
