What a row is

One line, ~1.5em, full-row hit target, mono. Emphasis is luminance, never a second font — the ramp the whole dashboard already uses. Collapsed rows carry a summary (step counts, diff stats, token figures); bodies are fetched only when a row expands, so the stream stays thin. What is deliberately not shown

Per-prompt harness chrome (mode, last-prompt, file-history-* — 9,963 of the 31,784 lines) is suppressed entirely in v1: “concise” rules it out, and an adapter can add an opt-in later without a schema change. system_prompt is a slot in your hierarchy that Claude Code never writes to the transcript — the tree simply has no such child for this client, rather than inventing one. Binary or base64 result bodies (playwright screenshots run to 220 kB, measured) are summarised by size, never inlined. All flagged in the design doc, §2, §3 and §7c.
