do-now as interrupt, not decoration

visual treatment · tasks #257 + #258 · proposal only · no production code

Recommendation: ship D1 · scoped rose ghost-outline on the selected do now control, paired with a storm field plus a restrained rose cast on the existing dreaming shader. Ordinary kinds stay calm indigo. Amber --warn remains the exclusive BROKEN signal.

Why now: the human asked for intentional danger-red on selected do-now (label, sliding indicator, hover/focus/pressed/disabled, keyboard, popout, transitions, reduced-motion) and for composable shader emotion axes rather than a hard-coded “red mode.” Implementation is blocked on the shared composer mount #241; this artifact is the approval gate.

#258 · shader emotion axes (not a red mode)

Map multi-float semantic inputs onto the existing uniforms (tintCur, hueCur, warp) rather than a boolean “danger shader.” Initial consumer: do-now selection eases the field stormier and slightly rose-cast; architecture stays reusable.

U · urgency
storm intensity → warp envelope depth + fractal curl gain. do-now target ≈ 0.55–0.75 sustained (not a one-shot pulse).
A · agitation
temporal unrest → advection / domain drift rate. Keep modest; high A without U reads as glitch, not interrupt.
V · valence
affect hue bias on composite. Negative valence → restrained rose (~ +0.04–0.08 pageTint toward danger hue), never full red plate.
easing
Same atmosphere τ as tint/hue today: exponential lerp 1 − exp(−dt / 0.6) (~600 ms time-constant). Selection change drifts; it does not snap. Reduced-motion: jump targets, freeze animation.
decay
Leaving do-now: U/A/V targets return to route ambient over the same τ. No sticky storm after kind change (pairs with successful do-now → add-idea #224).
compose
Simultaneous sources max by priority band: route ambient < selection emotion < hard fault (none yet). Do not sum unbounded floats. One writer on the shader handle per frame (existing window.dreambg pattern).
perf
≤ 0.3 ms extra CPU per frame for emotion math; no new GPU pass — only uniform targets. Existing 4-pass stack stays. Text always wins; luminance cap unchanged.
a11y / RM
Colour is not the only signal: selected kind label + outline already change. RM: static danger colour on control; shader holds final tint/hue, no warp animation. Prefer prefers-reduced-motion already wired in draw loop.

IGC snapshot

Goal

Selected do-now is unmistakably an interrupt; BROKEN and live remain distinct; ordinary commands stay calm; popout cannot drift.

Context

Ghost outline idiom, scarce accent, amber = fault, 4-pass shader with tint/hue/warp, shared composer still pending #241.

Surviving idea

D1 + U/A/V storm with restrained rose cast. D2 and hard red-mode refuted as defaults.

Decision requested
A · control radius Scoped rose ghost-outline on the selected do-now only (D1), or full-group hazard rail/wash (D2).
Recommend: A = D1 scoped.
B · field emotion Storm-only ambient under do-now, or storm + restrained rose cast via valence.
Recommend: B = storm + restrained rose.
C · token Adopt --danger: #f87171 distinct from --warn / --accent.
Recommend: C yes.
D · sequence Implement chrome + emotion on the #241 shared composer mount (not a main-only patch).
Recommend: D yes.
Recommended answer: Approve A=D1, B=storm+rose, C, D as recommended.
One clarifying option if he wants louder: keep D1 as default; allow a future settings-gated “hazard wash” experiment without making D2 the production baseline.
Implementation sketch after approval (not authorised yet)
  1. Add --danger to watch :root + watch-design colour rules (third colour, BROKEN stays amber).
  2. Kind-selected class on do-now only: danger text-shadow + .sgind border colour; slideIndicator unchanged geometry.
  3. Expose emotion targets on window.dreambg (setEmotion({u,a,v}) or discrete setters); map to existing tint/hue/warp targets; τ=0.6; RM snap.
  4. Wire selection in the single composer mount after #241; browser guards for colour + intermediate indicator travel + RM.
  5. No #237 work; no production changes in this design commit.
Contrast & non-goals

#f87171 on #0b0f19 ≈ 6.9:1 (AA large / UI component). Body text stays on the existing ramp; danger is for chrome, not paragraphs.

Non-goals: hard-coded red full-screen mode; using warn amber for urgency; new shader pass; emotion API in plugins v1; changing do-now command semantics or server priority (visual only until product says otherwise).
