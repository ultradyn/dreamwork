using the date already shown.

Each review row already carries the artifact file’s modification time and renders its age from that value. Sorting by the same value keeps the visible claim and ordering on one source of truth.

Recommendation

Sort descending by filesystem mtime, then ascending by filename as a deterministic tie-break.
reviews.sort(key=lambda r: (-r["mtime"], r["name"]))

This is a collector rule, not a browser-side re-sort: every reader receives the same order.
