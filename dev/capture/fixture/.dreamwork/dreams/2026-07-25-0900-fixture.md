# a dream, for the dashboard to render

The dashboard expands dreams as markdown prose, so this one is wrapped at
seventy-two columns like every file the loop writes, and it runs long
enough that a paragraph has to wrap more than once inside the reading
column.

## A heading, so the block renderer has one to place

- a bullet that itself wraps across more than one source line, because
  that is the case that used to join wrongly
  - a nested bullet, one level deeper
- a second bullet with `a/path.md` in it, and some *emphasis*

```
a fenced block   stays verbatim
```
