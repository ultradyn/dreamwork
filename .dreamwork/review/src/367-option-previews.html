How the numbers were obtained

No pixel figure in a caption was typed. On load, each shell runs the same measure: strip getBoundingClientRect().height, pill row count from distinct offsetTop values, wrap width, outer margin as page.left to wrap.left (the product gutter, not the shell border), reading column width, and position from data-current/data-total on the shell. The red-proof is mechanical: remove pills from option A’s markup and reload — height and row count in that caption change with no caption edit.
